# 2026-10-04候选的验收与发行边界

本轮源码包含启动器三语言、固定IDV Login 6.3.1 beta更新策略、国服/国际服共用网易内容下载链、ASCII默认安装根，以及Wine默认输入/输出设备跟随运行包。它们不是一次公开发行，发行号仍沿用原值。构建与实际个人安装是不同步骤：本机维护将现有游戏目录重命名为`IdentityV`并修正对应记录，保留可逆清单及小配置备份；不引入旧中文目录专用回退、扫描或重复数据副本。自定义路径与检索已下载游戏仅留未来规划。

## 为什么保留独立运行包与回退

玩家启动器App包含新的语言资源、helper合约8及共同下载管理器，默认运行环境采用新的设备跟随版本。签名音频载荷、manifest和catalog一起更新；本机以新的不可变slot选用它，保留旧audio1及原绑定备份，不在旧目录原位替换模块。源码实现、编译和合成检查无法证实设备驱动切换耗时或真实语音路径；保留旧运行包能按同一游戏环境比较并立即回退。独立stage工具验证源码及已签载荷，再在新目录构造运行包；早期工程ad-hoc产物不能直接安装为日常运行包。

维护依据分别见[语言说明](launcherLocalization.md)、[登录来源与策略审计](idvLoginSourceAudit.md)、[两服下载共链](downloadCoreUnification.md)及[`wineAudioPatch/`](../wineAudioPatch/README.md)。其中登录与下载都直接使用精确校验的上游程序；不是本项目原创登录或内容下载引擎。

## 最小剩余验收

1. 在最终签名候选上检查语言菜单持久化、三种语言主要页面的布局及系统语言回退；确认只改变启动器界面。
2. 首装/旧helper更新后验证固定官方登录组件可实际导入委派策略、正常登录，不出现组件自带更新对话框或启用远程热修复。该操作涉及原有受管helper/证书授权流程，应单独安排。
3. 实际国际服首装、取消续传与修复各验证一次；完整planner复验必须通过。真实服务与不透明下载核心的中断写入行为不能由协议测试推定。
4. 对新的音频运行包安排输出与输入的物理切换，核对快速连切、暂时无默认设备后恢复、退出释放及听感；接受约1–2秒静音目标，实测时长、爆音与驱动兼容性仍未知。不以热切换补丁宣称修复语音条气泡音。

这些是本轮行为的验收边界，不要求先做性能或对局压力测试才能实现代码。性能优化、气泡音根因和其他未来功能不自动成为1.0发布门槛。

## 公开发行前的必要项

默认runtime中的GDI补丁仍有构建源码路径残留，必须在公开发行前按源码路径映射重建并同步载荷哈希、manifest/catalog及检查，见[已知问题](knownIssues.md)。实际strip副本仍有运行态诊断路径，本轮保留原GDI，因此该项没有被完成。公开封包还需从最终干净源码重建、对最终载荷做第三方与私人路径审计、Developer ID签名、公证/staple及一次首装/升级验收。工程ad-hoc候选仅用于验证；日常App安装使用Developer ID签名并公证的候选，不能直接安装ad-hoc工程件。

恢复采用已保留的旧App/helper与不可变runtime版本，而不是在活动进程下替换模块。登录策略转换前的私有config备份可能含秘密，只留组件自己的owner-only状态目录，不进入公开日志或源码。
