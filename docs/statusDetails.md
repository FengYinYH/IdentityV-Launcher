## 2026-11-05 测试成本与去重核对

范围为本项目在当地11月5日的仓内工程记录、公开仓库 GitHub Actions 全部16次运行及当前隔离首装；仓内未记录的本地/来宾实验和私有任务无法从这些来源完整盘点，下面不是所有机器、流量和费用的完整账单。GitHub job运行时间按`started_at`到`completed_at`相加，未计算排队及GitHub计费倍率/取整；各run的具体job和artifact以[仓库Actions](https://github.com/FengYinYH/IdentityV-Launcher/actions)为准。

| 测试族 | run / job | job分钟约 | 可证明的范围 |
| --- | ---: | ---: | --- |
| 国际服公告观察 | 3 / 3 | 123.58 | 两次各约一小时的观察失败，保留画面/日志，不可当公告验收通过。 |
| 两服有界安装启动观察 | 3 / 6 | 43.02 | 不同版本的两服流程与失败/取消；其中一次国服job成功，国际服job失败。 |

| 真实首装 | 3 / 3 | 16.54 | 早期两次失败、后续一次job成功；须按具体源码和断言解读。 |
| 图形可行性/就绪 | 4 / 5 | 3.67 | 不同托管镜像/系统的图形前提，不等于完整游戏体验。 |
| 核心检查 | 1 / 2 | 3.80 | 合约及官方网络检查。 |
| **合计** | **16 / 21** | **231.74** | 作业墙钟时间之和，不是计费分钟。 |

17个现存CI artifact共10,168,571字节，其中两次长公告观察的artifact合计8,012,438字节；没有删除任何artifact。两个长观察分别对应不同提交和脚本迭代，事后可归为同一验收目标的重复消耗，但不能把当时为排查修改进行的重试简单认定为没有价值。托管系统、macOS15及macOS27来宾、真实桌面、模拟fixture分别提供不同证据；build20的macOS27来宾复用客户端完成正式启动/停止，macOS15曾越过容量门进入真实下载，不能将这些记录扩写为所有来宾完整首装和可视登录通过。

本机此次独立国际服清单17,602,266,736字节；从安装核心到完成清单校验成功后，复制到新的外置测试位置并再次验证，不重新全量下载。内置源约16 GiB、外置副本约16 GiB均保留；另有外置路径边界测试树，`du`逻辑大小约5.5 GiB，APFS克隆共享块使其不能直接等同实际新增物理占用。不要把空间快照相减当下载网络流量。此次也出现一次完整构建的临时DMG挂载失败，单项复测通过；不同源码的候选构建与并发重跑应分别记录，不能把中途包当最终提交。

后续先把测试目标、平台、源码提交、前置资源和可观察终点写成一行矩阵；代码不变时复用已验证的下载字节和fixture，只在变更影响安装交易、数据布局或首次下载时重做全量首装。日常CI保留快速合约、协议和网络检查；图形/真实游戏做带明确触发条件的有界任务，在同一宿主能力和相同脚本未变化时不重复一小时公告观察。虚拟机分别保留解决系统版本、容量API和进程隔离问题所必需的覆盖；真实桌面用于人可见热更新、公告和登录入口。将截图、网络字节数、job时间及清理归属明确记录，避免把日志、模拟、启动进程或GPU前提写成完整交互通过。
